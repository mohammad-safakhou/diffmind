# README media assets

These assets are captured from the generated DiffMind Demo Shop, never a
company workspace.

| File | Role |
| --- | --- |
| `diffmind-demo.gif` | Ten-second README overview assembled from four frames |
| `project-list.jpg` | Synthetic project card |
| `demo-shop-graph.jpg` | Six-service architecture graph |
| `graph-comparison.jpg` | Baseline and changed saved graphs |
| `operations-history.jpg` | Durable ingestion and operation history |

All static frames are 1920×1080 JPEGs. `make demo-media` rebuilds the 1200×675,
8-fps GIF and requires `ffmpeg`. Capture from a fresh public workspace, keep the
browser free of personal tabs or overlays, and reject any frame containing a
local username, private path, real organization name, credential or token.
