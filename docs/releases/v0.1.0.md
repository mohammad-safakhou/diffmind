# DiffMind v0.1.0

`v0.1.0` is the first public release of DiffMind: an evidence-backed architecture
graph for developers and coding agents.

## Highlights

- Deterministic multi-repository extraction with source evidence and saved graph
  history; no model API key is required to build a graph.
- Dependency, impact, path, object-trace and graph-comparison queries through the
  dashboard, HTTP API and MCP.
- Agent-first installation and workspace management, plus an optional manual UI.
- Extensible, tested knowledge packs for company conventions and framework gaps.
- Continuous refresh, bounded jobs, access controls, audit history, backup and
  recovery for a single-server team deployment.
- Public Demo Shop, pinned OpenTelemetry and Google benchmarks, and a generated
  10-team/150-service scale fixture for evaluation without private source code.

## Install

Download through the checksum-verifying installer:

```bash
diffmind_install_tmp=$(mktemp -d)
curl -fsSL https://raw.githubusercontent.com/mohammad-safakhou/diffmind/master/install.sh \
  -o "$diffmind_install_tmp/install.sh"
# Review the downloaded script before running it.
DIFFMIND_VERSION=0.1.0 DIFFMIND_INSTALL_DIR="$HOME/.local/bin" \
  sh "$diffmind_install_tmp/install.sh"
export PATH="$HOME/.local/bin:$PATH"
diffmind version --json
diffmind doctor
```

Supported release targets are Linux and macOS on amd64 and arm64. Git remains a
runtime dependency. Windows binaries are not provided.

## Verification

Before tagging, `make verify` passed the full Go and race suites, pack and
distribution checks, 39 frontend tests, both frontend audits, production builds,
and `govulncheck`. Release CI repeats verification, then builds and runs the
native installed-archive acceptance gate independently on all four targets before
publishing any asset.

## Known limits

This is a pre-1.0, single-server release. Distributed workers, identity-provider
group synchronization, path/schema migration, encrypted off-host backups,
Windows support, code signing/notarization and universal framework coverage are
not included. Public benchmarks deliberately expose coverage gaps. See the
[roadmap](../ROADMAP.md) and [tested support matrix](../supported-patterns.md).
